# Gaussian-integer spectra of random sign matrices

Paper on the probability that every eigenvalue of an $n\times n$ matrix with independent, uniformly random $\pm1$ entries is a Gaussian integer. Vu conjectured that this probability is $2^{-(1+o(1))n^2}$ (Conjecture 9.5 in V. Vu, *Recent progress in combinatorial random matrix theory*, [arXiv:2005.02797](https://arxiv.org/abs/2005.02797)).
